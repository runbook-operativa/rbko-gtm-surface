# rbko-gtm-surface

Static files of the Runbook Operativa lote surface (GitHub Pages). Built from the private repo `rbko-gtm`
(`scripts/deploy_surface.py --publish`); do not edit here.

Contains no data and no secrets: `config.js` holds only the Supabase project URL and its publishable (anon) key,
which is public by design. All data is protected by row-level security and requires a magic-link login.
